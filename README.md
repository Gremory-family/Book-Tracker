## Описание
Графическое приложение для отслеживания прочитанных книг.
Позволяет добавлять книги с полями: название, автор, жанр, количество страниц.
Реализована фильтрация по жанру и по количеству страниц (> заданного числа).
Данные автоматически сохраняются в JSON-файл при добавлении книги.
Также есть кнопки ручного сохранения и загрузки.

### Возможности программы
- Заполнение прочинаых книг
- Сортирвка книг по жанру
- Сортировка книг по количеству страниц

### Проверка корректности ввода:
- **Заполнение полей:** все поля должны быть заполнены кроме поля "страницы".
- **Проверка правильности ввода страниц:** в поле для указания страниц, допустимы только положительные числа! При вводе букв или отрицательных числе, выдаёт предупреждение!
